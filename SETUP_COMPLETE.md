## 🚀 Quick Start

### To Get Started (Literally Right Now)
```bash
# From project root
npm install          # Install all dependencies
cd server && npm install
cd ../client && npm install
cd ..

# Configure
cd server
cp .env.example .env
# Update MONGO_URI in .env

# Run it!
npm run dev
```

✅ Open http://localhost:5173
