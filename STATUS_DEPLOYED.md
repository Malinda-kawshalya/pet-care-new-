## 📞 Troubleshooting

### Servers not starting?
1. Check ports 5000 and 5173 are available
2. Verify MongoDB connection
3. Check environment variables in .env
4. Review error messages in terminal

### Cannot login?
1. Ensure demo accounts are seeded
2. Check email is correct (case-insensitive)
3. Check password (case-sensitive)
4. Try admin account if available

### Email not working?
1. In development, check browser console for tokens
2. Check EMAIL_HOST and EMAIL_PORT in .env
3. For Gmail, verify app-specific password
4. Review .env configuration

### Admin functions unavailable?
1. Ensure logged in as admin
2. Check admin role in database
3. Verify JWT token is valid
4. Check browser console for errors
